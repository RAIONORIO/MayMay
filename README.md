# MayMay

MayMay é uma assistente pessoal baseada em inteligência artificial, desenvolvida para funcionar prioritariamente de forma local no Windows.

## Objetivos iniciais

- Conversação natural em português
- Uso de modelos locais pelo Ollama
- Histórico e memória local
- Execução segura de ferramentas
- Controle do Windows
- Interface desktop própria
- Reconhecimento e síntese de voz
- Integrações pessoais
- Automação de tarefas

## Arquitetura inicial

- Python: backend, inteligência, agentes, memória e ferramentas
- Ollama: execução local dos modelos
- SQLite: histórico, memória e configurações
- React e TypeScript: interface
- Tauri e Rust: integração desktop com Windows
